    Code

    The architecture and logic within the code:

    Both shell entry points source src/sync_common.sh. This shared module provides the err, warn, info, and debug logging functions, as well as start_group and end_group for GitHub Actions log groups. Keeping these workflow commands in one place ensures consistent output across setup and sync operations.
